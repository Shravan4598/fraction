# Versioning Policy

Fraction follows **Semantic Versioning**.

| Version | Meaning                                  |
| ------- | ---------------------------------------- |
| MAJOR   | Breaking API changes                     |
| MINOR   | New features with backward compatibility |
| PATCH   | Bug fixes and documentation improvements |

Example progression:

```text
1.0.0
1.0.1
1.1.0
1.2.0
2.0.0
```
